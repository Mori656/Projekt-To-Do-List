# Projekt To Do List

Aplikacja webowa typu TODO list stworzona jako projekt edukacyjny. Umożliwia zarządzanie zadaniami, filtrowanie według stanu i priorytetu, wyszukiwanie, oraz korzysta z nowoczesnego interfejsu React + MUI.

## Link do strony
- Strona GithubPages: https://mori656.github.io/Projekt-To-Do-List/

## Demo

- Lokalny demo: http://localhost:3000/Projekt-To-Do-List/

> Uwaga: Demo dostępne po uruchomieniu serwera aplikacji w katalogu `todo-app`.

## Uruchomienie

1. Otwórz terminal w folderze `todo-app`.
2. Zainstaluj zależności:
   ```bash
   npm install
   ```
3. Uruchom aplikację deweloperską:
   ```bash
   npm run dev
   ```
4. Otwórz przeglądarkę i przejdź do:
   ```
   http://localhost:3000/Projekt-To-Do-List/
   ```

## Użyte technologie

- React
- TypeScript
- Vite
- Material UI
- React Router
- React Query
- Tailwind CSS
- Zod
